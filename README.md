# IFM 播客客户端

## 项目简介
IFM 是一款简单的播客客户端，支持播放播客节目、生成 RSS Feed 和查看节目列表。

## 技术栈
- 前端：HTML, CSS, JavaScript
- 后端：Node.js, Express
- 数据库：MongoDB

## 功能
- 播放播客节目
- 生成 RSS Feed
- 查看节目列表
- 提交和查看评论

## 使用方法
1. 克隆仓库：`git clone https://github.com/si1ver2333/IFM.git`
2. 安装依赖：`npm install`
3. 启动服务器：`npm start`
4. 访问应用：`http://localhost:3000`
